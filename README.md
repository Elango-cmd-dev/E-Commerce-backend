# E-Commerce Backend API

A backend application built using Java and Spring Boot for managing an E-Commerce platform. The application provides RESTful APIs for product management, user management, order processing, and database integration.

## 🚀 Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* Maven
* REST API
* Hibernate

## ✨ Features

* User Management
* Product Management
* Category Management
* Order Management
* Shopping Cart Functionality
* Database Integration with MySQL
* Exception Handling
* RESTful API Development
* Layered Architecture (Controller, Service, Repository)

## 📂 Project Structure

* Controller Layer
* Service Layer
* Repository Layer
* Entity Layer
* DTO Layer
* Configuration Layer

## 🛠️ Setup Instructions

1. Clone the repository
2. Configure MySQL database
3. Update application.properties
4. Build the project using Maven
5. Run the Spring Boot application

## Database Configuration

Update the database configuration in application.properties before running the application.
